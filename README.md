# financieel-dashboard

Versleuteld persoonlijk dashboard, gehost via GitHub Pages. `index.html` bevat alleen AES-256-GCM-versleutelde data (sleutel uit wachtwoord via PBKDF2, 600.000 rondes); zonder wachtwoord staat er niets leesbaars in. De bron en de pipeline staan in de privérepo `financieel-beheer`.
